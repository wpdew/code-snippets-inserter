## [2.0.6] - 2026-05-02

### 🐛 Виправлено
- **КРИТИЧНЕ:** Виправлено роботу placeholders `${1:text}` в snippets
- Проблема: regex `/\$/g` екранував ВСІ долари, включно з `${1:Models}` → `\${1:Models}`, що ламало placeholders
- Рішення: використання negative lookahead `/\$(?!\{)/g` для екранування тільки НЕ-placeholder доларів
- Тепер `${1:Models}` працює як табстоп, а `$price_old` екранується коректно
- Приклад: `namespace App\${1:Models};` тепер дозволяє редагувати "Models" з табуляцією

## [2.0.5] - 2026-05-02

### 🐛 Виправлено
- **КРИТИЧНЕ:** Виправлено видалення PHP змінних при вставці snippets
- Проблема: VS Code SnippetString інтерпретує `$variable` як placeholder
- Рішення: додано екранування $ для SnippetString API після розекранування з JSON
- Ланцюжок обробки: JSON (`\\$`) → parse (`\$`) → unescape (`$`) → escape для SnippetString (`\$`) → вставка (`$`)
- Тепер PHP змінні (`$price`, `$_GET`, `$_SESSION`) вставляються коректно

## [2.0.4] - 2026-05-02

### 🐛 Виправлено
- **КРИТИЧНЕ:** Виправлено розекранування $ символів при вставці snippets
- Змінено split/join на regex для правильного екранування
- Проблема: `'\$'` в JS = `'$'` (не валідний escape), тому split не працював
- Рішення: використання regex `/\\\$/g` для пошуку backslash + dollar
- Тепер PHP змінні (`$price`, `$_GET`, `$_SESSION`) вставляються коректно
